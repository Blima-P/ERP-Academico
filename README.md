# ERP Acadêmico - Trabalho N2 🎓

Projeto React desenvolvido para a matéria de **Programação Web** (UCB - Terça Noturno).

###  Requisitos Cumpridos
- **Login:** Autenticação simulada com controle de sessão e logout.
- **CRUDs:** Três módulos completos (Create, Read, Update, Delete) usando `useState` e `map()`.
- **Relatório:** Tela de relatório com lógica de JOIN entre entidades.
- **Segurança:** Rotas protegidas (só acessa o sistema após o login).

### Tecnologias
- React JS
- HTML / CSS
- LocalStorage (para salvar os dados) 

###  Como usar
1. `npm install`
2. `npm start`
